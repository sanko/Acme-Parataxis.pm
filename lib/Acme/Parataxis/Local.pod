=head1 NAME

Acme::Parataxis::Local - A per-fiber storage slot

=head1 SYNOPSIS

    use v5.40;
    use Acme::Parataxis qw[async fiber];
    use Acme::Parataxis::Local;

    my $request_id = Acme::Parataxis::Local->new;
    my $trace_id   = Acme::Parataxis::Local->new( inherit => 1 );   # flows into spawned children

    async {
        $request_id->set(42);
        $trace_id->set('span-1');
        fiber { $request_id->set(99); say $request_id->get };   # 99  (request_id is walled off)
        fiber { say $trace_id->get };                           # span-1  (trace_id was inherited)
        say $request_id->get;                                   # 42
    };

=head1 DESCRIPTION

A named value slot that reads differently depending on which fiber asks. Fibers never see each other's values: a child
won't see what its parent wrote, and siblings can't clobber one another. This is the opposite of C<local>: the value
follows the fiber, not the dynamic call stack.

It is designed for ambient, fiber-scoped state that must not leak sideways - tracing ids, span context, a database
handle chosen per fiber - with no changes to the scheduler or C code. Each C<Local> object is one logical variable;
create as many as you need.

=head1 INHERITANCE (TRACE PROPAGATION)

A slot created with C<inherit =E<gt> 1> opts into upward propagation: the value it holds is copied from the spawning
fiber into each child the moment the child is spawned (via C<fiber>, C<async>, a C<nursery> child, or an actor's
mailbox fiber). A fiber spawns a child with the value it holds at that instant - a shallow copy the child then owns
exclusively, so later C<set>s on either side never cross. Write C<inherit =E<gt> 1> on a trace-id or span-context slot
and it rides along without threading it through every constructor. Plain slots (the default) keep strict per-fiber
isolation.

=head1 METHODS

=head2 C<new( [ default =E<gt> $default, inherit =E<gt> 0|1 ] )>

Creates a slot. A single C<Local> object can be referenced from any number of fibers; each fiber holds its own copy.
The optional C<default> is what C<get> returns until that fiber writes (explicitly, setting C<undef> counts as
writing). The optional C<inherit> flag (default false) seeds spawned children with this slot's current value, as
described above.

=head2 C<get()>

Returns the calling fiber's value for this slot: the value C<set> wrote for it, or the C<default> if it never wrote.
Croaks outside a scheduled fiber.

=head2 C<set( $value )>

Writes the calling fiber's value for this slot and returns it. Croaks outside a scheduled fiber.

=head1 HOW IT WORKS

Values live in a stash keyed by the fiber B<object> (not its id, see below), pruned the moment a fiber is observed done
or its object is destroyed. No scheduler or C changes are required.
