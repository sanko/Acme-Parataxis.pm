=head1 NAME

Acme::Parataxis::Channel - A simple message queue for inter-fiber communication

=head1 SYNOPSIS

    use Acme::Parataxis;
    use Acme::Parataxis::Channel;

    my $q = Acme::Parataxis::Channel->new( capacity => 1024 );

    async {
        fiber { $q->put( $_ ) for 1 .. 8 };      # producers
        say $q->get for 1 .. 8;                  # consumer
    };

=head1 DESCRIPTION

A simple message queue that allows you to send and receive data between fibers. If the channel is full, writers block;
if it is empty, readers block. Both ends can be used by as many fibers as you want concurrently.

A channel of size C<1> is a rendezvous point (no buffering: C<put> waits for a matching C<get>); to buffer one element
use size C<2>, and so on.

Channels are internally implemented using two L<Acme::Parataxis::Semaphore> instances to coordinate producers and
consumers.

=head1 CONSTRUCTOR

=head2 C<new( [...] )>

    my $ch = Acme::Parataxis::Channel->new;
    my $ch = Acme::Parataxis::Channel->new(capacity => 10);
    my $ch = Acme::Parataxis::Channel->new(capacity => 10, timeout => 200);

Creates a new channel. The optional C<capacity> parameter sets the maximum number of items the channel can hold and
defaults to C<2_000_000_000>. The optional C<timeout> parameter (non-negative milliseconds, default C<0>) sets a
per-channel default wait bound: a C<get> or C<put> that would otherwise park waits at most C<timeout> milliseconds
before dying with C<Acme::Parataxis::Error::Timeout>. C<timeout =E<gt> 0> (the default) disables the bound, as does
C<timeout =E<gt> undef>. The effective bound is reported by C<timeout( )>.

=head1 METHODS

=head2 C<timeout( )>

    my $ms = $ch->timeout;

Returns the channel's default wait bound in milliseconds (C<0> when none was configured).

=head2 C<put( $value )>

    $ch->put($value);

Append a value to the channel. Blocks the current fiber if the channel is at capacity, waiting until space becomes
available. If the channel has a default C<timeout> bound (see C<new( )>), the wait honors it and dies with
C<Acme::Parataxis::Error::Timeout> when the bound expires.

=head2 C<put_priority( $value )>

    $ch->put_priority($value);

Append a value to the channel. Bypasses any yield or parks even if the mailbox is full.

=head2 C<get( )>

    my $value = $ch->get;

Remove and return the next value from the channel. Blocks the current fiber if the channel is empty, waiting until a
value is available. If the channel has a default C<timeout> bound (see C<new( )>), the wait honors it and dies with
C<Acme::Parataxis::Error::Timeout> when the bound expires.

=head2 C<size( )>

    my $n = $ch->size;

Returns the number of items currently in the channel.

=head2 C<adjust( $diff )>

    $ch->adjust( $diff );

Adjust the channel capacity by C<$diff>. This can be used to grow or shrink the effective capacity at runtime.

=head2 C<shutdown( )>

    $ch->shutdown;

Shut down the channel by releasing a large number of permits on the internal get semaphore. This unblocks any fibers
waiting on C<get( )>, allowing them to drain remaining items.

=head2 C<remove_waiter( $fid )>

    my $removed = $ch->remove_waiter($fid);

Unregister a fiber that is currently blocked in C<get>/C<put>. Returns the total number of waiter entries removed
across both internal semaphores (0, 1, or 2). A removed waiter is never woken by a later C<put>/C<get>/C<shutdown>; the
caller takes responsibility for reclaiming that fiber (typically by destroying it).

=head2 C<try_get( )>

    my ( $ok, $value ) = $ch->try_get;

A non-blocking variant of C<get>. If a value is available it is removed and returned as C<(1, $value)>; otherwise it
returns C<(0, undef)> without parking the current fiber.

=head2 C<try_put( $value )>

    my $ok = $ch->try_put($value);

A non-blocking variant of C<put>. If there is room in the channel the value is appended and C<1> is returned; otherwise
it returns C<0> without parking the current fiber.

=head1 SELECT

=head2 C<select( %args )>

    my ( $ch, $value ) = Acme::Parataxis::Channel->select(
        [ $left,  'get'          ],
        [ $right, 'put', $msg    ],
        timeout => 1_000,
    );

Called as a class method (not on a channel instance). Selects the first ready case, operating on the channel as if the
matching C<get> or C<put> had been called, and returns C<( $channel, $value )> - the channel that fired and, for a
C<get> case, the value read from it (C<put> cases return the value they wrote).

Each case is an array reference C<[ $channel, op, $value? ]>; C<op> is C<get> or C<put>, and C<put> cases require the
value argument. More than one case may be given, and cases are tried in random order so a single ready case cannot be
starved. An optional C<timeout> (non-negative milliseconds) bounds the wait - when it fires before any case is ready,
select returns C<( undef, undef )> and an optional C<default> is a code reference run (and returned as the value) when
no case is ready and nothing is pending, without ever blocking. Giving at least one case is required, as is calling
select from inside a scheduled fiber (C<async { ... }> or the run block). When C<timeout> is omitted, each case
channel's own default bound (see C<new( )>) applies and select parks until the earliest such bound fires; an explicit
C<timeout> option always wins over the channel defaults.

Each case channel parks the selecting fiber on a private waiter list (see C<select_waiters> below). Only channels being
selected on are affected; a fiber parked in C<select> is interrupted by C<with_timeout>/cancellation tokens like any
other park. The implementation is two-phase: ready cases are probed first without yielding, and only when none is ready
does select register on every involved channel and park until the first wake.

=head2 C<select_waiters( )>

    my $n = $ch->select_waiters;

Returns how many fibers are currently parked in C<select( )> on this channel, split by nothing - just the scalar count.
Introspection helper; primarily useful in tests.
